# DD1 Game Portal (`dd1.co.in`)

Static web portal and informational guide site for the **DD1 Game** Android APK (`v1.0.4`) and related guides, hosted on GitHub Pages.

## Repository Structure

- `Index.html` — Main landing page, game gallery, app specifications, withdrawal limits, referral guide, and FAQ schema
- `about-us.html` — About page
- `contact-us.html` — Contact page
- `disclaimer.html` — Legal & regional disclaimer page
- `privacy-policy.html` — Privacy policy page
- `robots.txt` — Search engine crawler instructions
- `sitemap.xml` — XML sitemap for indexing
- `logo.png` — Brand logo and icon (`192x192`)
- `dd1-game-photo-1.jpg` — Popular games gallery image 1
- `dd1-game-photo-2.jpg` — Popular games gallery image 2
- `dd1-game-photo-3.jpg` — Popular games gallery image 3

### Guide Folders
- `dd1-apk-download-install-guide/` — APK download and installation guide
- `dd1-upi-withdrawal-guide/` — UPI withdrawal rules and guide
- `dd1-make-money-beginner-tips/` — Beginner tips guide
- `dd1-login-otp-problem-fix/` — Login and OTP troubleshooting guide

## How to Update on GitHub
1. Edit or upload files directly in the [`Dd1`](https://github.com/ajayjada2624/Dd1) repository on the `main` branch.
2. Keep image file names in lowercase with hyphens (such as `dd1-game-photo-1.jpg`) and match the exact `src` path in `Index.html`.
3. Commit changes to publish updates via GitHub Pages.
